# 원신 · 바람이 시작되는 곳 (Genshin Impact WebGL Clone v2)

Three.js + TypeScript + WebGL2로 구현한 고퀄리티 3D 오픈월드 액션 RPG 클론입니다.

## 실행 방법
- **간편 실행**: `PLAY.bat` 더블클릭 (자동 빌드 후 브라우저 실행)
- **개발 서버 실행**: `npm install` 후 `npm run dev`

## 6원소 플레이어블 캐릭터 & 파티 편성 (`L`)
1. **여행자 (바람 / 한손검)** — `E` 풍압검(몹몰이+확산) / `Q` 격동의 바람(타 원소 흡수 회오리)
2. **다이루크 (불 / 대검)** — `E` 역날의 화염(3연타) / `Q` 여명(화염 불사조 돌진 + 불 원소 부여)
3. **모나 (물 / 법구)** — `E` 수중 환영(도발+물 폭발) / `Q` 별의 운명(성좌 포영 +45% 피해 증가) · **수면 고속 질주!**
4. **각청 (번개 / 한손검)** — `E` 성신 회귀(번개 쐐기 순간이동) / `Q` 천가 유검(고속 번개 참격)
5. **카미사토 아야카 (얼음 / 한손검)** — `E` 얼음꽃(얼음 부여) / `Q` 멸망의 서리(거대 회전 서리 폭풍) · **수면 빙결 질주!**
6. **종려 (바위 / 장병기)** — `E` 지핵(바위 기둥 + **옥홀 방패 6,500 보호막**) / `Q` 천성(**거대 운석 낙하 + 4.5초 석화!**)

## 조작법
| 키 | 동작 |
|---|---|
| `W A S D` | 이동 / 절벽 등반 / 수영 |
| `Space` | 점프 / 공중 **바람의 날개(활강)** 펼치기 & 접기 |
| `Shift` / `우클릭` | 대시 회피 · 질주 (모나/아야카 수면 위 고속 이동!) |
| `좌클릭` | 일반 4연격 / 길게 누르기 **강공격** / 공중 **낙하 공격** |
| `E` / `Q` | 원소 전투 스킬 / 원소 폭발 (컷신 배너 + 카메라 줌) |
| `1` ~ `4` | 현재 파티 캐릭터 교체 |
| `V` / `가운데 클릭` | **원소 시야** (주변 보물상자 · 눈동자 · 선령 · 원소 비석 탐지!) |
| `F` | 상호작용 (일곱신상 · 워프 · 보물상자 · 채집 · 수정 나비 · 모닥불 요리 · 비경 입장) |
| `L` | **파티 편성** (6인 중 4인 자유 편성 + 원소 공명 적용) |
| `C` | 캐릭터 스탯 · **성유물 5세트 장착** · 무기 교체 및 제련 |
| `B` / `H` | 배낭 · **요리 타이밍 미니게임** · 선도장 버프 / 간편 회복(`H`) |
| `M` | 티바트 월드맵 & 빠른 워프 이동 |
| `F3` | **기원 (가챠)** — 별똥별 컷신 1회/10회 뽑기 |
| `T` / `P` | 시간 돌리기(새벽/낮/노을/밤, 야간 가로등 점등) / **사진 모드(PNG 저장)** |
| `Alt` / `F1` / `Esc` | 커서 표시 / 조작 안내 / 페이몬 설정 메뉴 |
